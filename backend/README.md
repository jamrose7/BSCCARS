# BSCCARS Backend Scaffold

This is a minimal Express.js backend scaffold for the BSCCARS system.
It is designed as a starting structure for implementing authentication,
complaints management, and resident data handling using MySQL.

---

## 📌 Purpose

This backend currently serves as a **development scaffold**:
- Defines API structure
- Simulates responses using mock data
- Prepares integration points for MySQL database implementation

All endpoints are intentionally minimal and will be replaced with
real database-backed logic.
